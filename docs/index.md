### Project Summary

Our team is developing an automated laundry folding device designed to make folding clothes easier and more convenient. The project combines mechanical components, sensors, and an embedded control system to automate the folding process with minimal human assistance.

My individual subsystem focuses on garment presence detection using a photoresistor, along with a signal-conditioning circuit, power supply, control buttons, and status LED. These components will help the system detect clothing and communicate with other subsystems to initiate or stop the folding process.

For more information about our team's design ideation and detailed progress, visit our [Team 209 Project Report](https://asu-egr304-2026-f-209.github.io/ASU-EGR304-2026-F-209/).
