# Component Documentation

This section provides a summary of the major components selected for my Automated Laundry Folding Device individual subsystem.

## Selected Components

| Component | Selected Part | Purpose |
|---|---|---|
| Photoresistor | PDV-P8103 | Detect garment presence |
| Operational Amplifier | MCP6004-I/P | Sensor signal conditioning |
| Voltage Regulator | L7805ABV-DG | Regulate 9 V input to 5 V |
| Wall Power Adapter | WR9HD1000CCP-F(R6B) | Supply 9 V DC power |
| Microcontroller | PIC18F57Q43 Curiosity Nano | Process sensor inputs and control outputs |
